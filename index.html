About

How I work

I moved into consulting from software development. I founded a delivery startup and built its app and its point-of-sale system myself before I ever touched Fusion. So when I write an MD.050 for a custom report or alert, I write it for the developer who has to build it, because I used to be that developer.

I run workshops and training in Arabic and write the documentation in English, so the people using the system understand it and the client keeps an auditable record. Training, UAT and handover get the same attention as configuration.
